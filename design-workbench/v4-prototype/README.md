# 《AI在5000天·伍力全开》V4 可交互原型

本目录是基于现有前端视觉基线、8 张批注稿与 OpenDesign Local Codex 生成结果整理出的单文件高保真原型。它用于确认界面层级、操作逻辑与开发边界，不替代生产业务代码。

## 交付内容

- `wqt-scoring-prototype.html`：可直接运行的交互原型。
- `brand-spec.md`：颜色、字体、间距、组件状态与响应式约束。
- `assets/`：从现有前端复用的品牌、角色和原卡背景资产。
- `verify_prototype.py`：Playwright 端到端回归脚本。
- `screenshots/`：登录、游戏空状态、卡片反馈和开发说明四个验收画面。

## 运行原型

直接用浏览器打开 `wqt-scoring-prototype.html`。原型完全在客户端运行，不需要启动后端。

推荐演示路径：

1. 输入 11 位手机号、至少 6 位密码，完成演示安全验证并同意协议。
2. 登录后输入五位大写活动码 `WQTAY`。
3. 选择活动，配置标准、快速或自定义模式。
4. 进入桌游模式，输入 `B01` 或打开“快速选卡”。
5. 选择卡牌选项，查看原卡背景、反馈、五力变化和演示音频状态。
6. 验证左栏互斥展开、暂停/恢复、终止二次确认，以及“开发说明·状态地图”。

## 批注落实

- 删除批注图 8 对应的独立页面，不保留重复流程。

## 状态与开发契约

核心状态流：

`登录 → 活动码校验 → 活动选择 → 模式配置 → 游戏空态 → 快速选卡/读卡 → 选择选项 → 反馈 → 下一张`

实现生产版本时需接入：

- 阿里云验证码服务与真实安全验证。
- 登录、活动授权、卡牌读取、计时同步及游戏事件 API。
- 录音上传、反馈音频与网络重试策略。
- 服务端权限、错误码、加载态和离线恢复策略。

当前原型使用客户端演示数据；验证码、活动和卡牌结果不应被视为真实授权来源。

## 自动验收

脚本覆盖登录门禁、五位活动码、三种模式、首个活动索引、左栏互斥、卡牌筛选与选中、反馈与属性变化、音频提示、暂停/恢复、开发说明和终止确认。

```powershell
python .\verify_prototype.py
```

通过标志：

```text
PASS: login -> activity -> config -> game -> picker -> feedback -> pause/stop
```
