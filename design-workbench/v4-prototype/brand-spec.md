# 《伍力全开》V4 原型品牌规格

V4 使用深靛不透明承载面、紫色主行动和青色交互反馈，并保留官方 Logo、小伍 IP 与真实卡牌的蓝黄电路视觉。

```css
:root {
  --bg: oklch(11% 0.055 274);
  --surface: oklch(22% 0.090 271);
  --fg: oklch(97% 0.014 275);
  --muted: oklch(72% 0.055 270);
  --border: oklch(45% 0.110 270);
  --accent: oklch(61% 0.235 285);
}
```

- 展示字体："Noto Serif SC", "Songti SC", serif
- 正文字体："Microsoft YaHei UI", "Noto Sans SC", sans-serif
- 等宽字体："Cascadia Mono", "SFMono-Regular", monospace
- 正文承载层保持高不透明深靛；半透明只用于外壳边缘与浮层。
- 紫色仅用于主要动作与选中态，青色用于输入焦点、读取反馈和系统连接态。
- 组件使用 1px 蓝紫边界、轻微顶部内高光和 8px 基础间距节奏。
- 五维色只在属性标记、卡牌背景与变化反馈中出现，不形成彩色按钮墙。
- 品牌资产只引用业务项目中的官方本地文件，不重绘或替换。

## 响应式约束

- `≤900px`：登录页隐藏装饰插画，游戏左栏收窄，卡牌选项改为单列。
- `≤620px`：游戏区切换为纵向布局；左栏保留“编号 + 名称”，三个入口等宽排列。
- 安全验证按钮不可被 flex 压缩；活动码、卡牌输入、弹层和开发说明不得产生页面级横向滚动。
- 关键操作保留不少于 44px 的触控高度，并提供可见的键盘焦点样式。
