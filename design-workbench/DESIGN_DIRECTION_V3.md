## 视觉提取

### 1. 城市场域

城市封面不是普通“紫色渐变”。它的识别来自四层空间：

- 最深层是近黑靛蓝夜空，承载星点和大面积呼吸空间。
- 中层是具有实体体积的蓝靛建筑与圆形平台，不是透明玻璃。
- 前层由青蓝路线、紫蓝环轨和少量紫红能量边缘勾出运动方向。
- 光不是铺满屏幕的霓虹，而是集中在轨道、建筑轮廓、设备屏幕和角色护目镜。

8 色量化显示城市主色均处于同一蓝靛 hue family：`#040A4A`、`#0A187F`、`#152F94`、`#303AB4`、`#3455CB`、`#555FDF`、`#6185F0`、`#96A5F6`。这意味着 V3 应用需要“同色相的空间明度层级”，而不是随意组合多种紫色渐变。

### 2. 小伍 IP

三组年龄形态共同特征：

- 圆润头身与设备轮廓、较大的护目镜/耳机、友好开放的表情。
- 深靛服装是大面积稳定色，蓝紫拼接形成身体动势。
- 青色只落在护目镜、袖口、鞋和设备边缘；洋红只作极少量服装能量缝线。
- 2–5 岁更圆、更高明度；6–11 岁最适合作为本系统默认语气；12–15 岁比例更修长、深色面积更大。

组件不直接复制角色造型，而提取其形态语言：胶囊按钮、柔和连续圆角、稍微前倾的运动切角、青色交互边缘、紫色内容层和低频洋红能量点。

### 3. Banner 材质

`banner-bg.png` 的主要颜色为 `#000122`、`#03042A`、`#0B0B3A`、`#15144C`、`#201D5F`、`#2F2B75`、`#4D4CA6`。它提供了 UI 的低噪声底层材质：深色实底、细密光带、少量电路/星点。适合做应用背景与空态氛围，不适合直接作为每张卡片纹理。

### 4. V2 可继承内容

- 三栏工作台和固定状态条已经建立稳定现场节奏。
- 情境卡有明确的标题、正文、选择、反馈顺序。
- 五力色已经被压缩为局部字母 chip，继续保持。
- V2 的 14px 圆角和克制阴影可保留比例，但需要变成“小伍设备外壳”式轮廓。

## 选定体系：Future Guardian Deck

### 色彩比例

- 58% 深靛场域：`#050824` / `#080D36` / `#0D1648`
- 27% 可读实色面板：`#121C4A` / `#172557` / `#1D2E63`
- 9% 蓝紫主光：`#625BFF` / `#7B72FF`
- 4% 青色交互高光：`#2BD9FF`
- ≤2% 洋红能量/危险提示：`#F05BDA`，不作大面积 CTA

五力色仍只用于字母 chip、3px 进度、雷达节点。成功绿、警告黄、危险红只在真实状态出现。

### 单一 token 来源

V3 运行时视觉只从 `expedition.css` 的 `@layer guardian-v3` 根 token 获取：

- `--space-0`：应用最深背景
- `--space-1`：导航/状态底
- `--surface-panel`：侧栏与数据模块，实色不透明
- `--surface-raised`：情境卡与弹窗
- `--surface-selected`：选中态
- `--surface-feedback`：反馈承载面
- `--text-primary / secondary / muted`
- `--action-primary`：蓝紫主行动
- `--action-highlight`：青色 hover/focus
- `--energy-magenta`：极小面积能量提示
- `--line / line-strong / glow`

### 表面与空间

1. 应用背景允许出现 banner 式星点、远处光轨和轻微紫蓝 halo。
2. 顶栏和全局状态条采用深靛实色，不能使用模糊到影响文字的玻璃。
3. 普通面板使用 `#121C4A` 附近实色；raised 卡片提升到 `#172557` 或 `#1D2E63`。
4. 情境正文区域使用最稳定的深蓝实色，正文不叠加纹理、星点或强渐变。
5. 高度只通过相邻明度、1px 蓝紫边框和克制阴影区分；不使用满屏发光描边。

### 光效

- 轨道光：细、连续、低透明度，用于页边和进度。
- 青色交互光：只在 focus、hover、active 的边缘出现。
- 蓝紫主光：用于 CTA、active tab、关键进度和情境卡顶部轨道。
- 洋红：只允许在录音、能量提示或极小装饰节点，不得成为大按钮背景。

### 形态

- 面板半径 16–20px，按钮 10–14px，chip 为胶囊形。
- 面板角落可以有一处“小伍耳机环”式弧形轮廓或短轨道，但不能每个角都做科技切角。
- 按钮强调饱满、圆润和可按压感，不做尖锐军用 HUD。
- 状态圆点与阶段点使用小伍护目镜式圆点/短光条，动作感来自连续轨迹而非闪烁。

### 字体与可读性

- 中文正文保持当前尺寸/行高，使用稳定的 UI 黑体；大标题可继续用宋体形成卡牌叙事感。
- 正文目标对比不低于 4.5:1；关键大字不低于 3:1。
- 面板必须有 ≥92% 的实色承载，禁止在正文后使用透明玻璃和复杂城市图。
- 青/紫状态必须同时有图标或文字，不能只靠颜色。

### 年龄亲和度

- 面向 9–16 岁，不走低龄糖果色，也不做成人电竞控制台。
- 圆润外壳、清晰大字、友好空态和有限色彩继承小伍的亲和力。
- 深色与城市空间提供成长感；轻量动势和青色反馈保留游戏活力。

## 明确禁止

- 通用紫色渐变白卡。
- 透明玻璃叠满城市图、正文透出复杂纹理。
- 细密 HUD 刻度、扫描线、等宽小字墙、全屏霓虹描边。
- 五力五色抢占主视觉。
- 洋红 CTA、彩色按钮墙、过度发光。
- 重绘小伍或生成替代 Logo；母版中的 IP 只作为形态/配色参考，不嵌入生产 UI。

## UI 母版检查标准

- 1440×900 完整核心对局，不改变 V2 三栏结构。
- 情境正文、三个选项和反馈在 900px 高度内清晰可读。
- 深靛、实色面板、蓝紫主光、青色交互形成明确职责。
- 五力色面积 ≤3%，洋红 ≤1%。
- 画面能与城市封面放在同一产品中，同时保持监督/资料类页面可扩展性。
