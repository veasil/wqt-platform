## 1. 系统角色与权限

### 角色一览

| 角色 | 标识 | 说明 | 可登录后台 |
|------|------|------|:-------:|
| Boss | `boss` | 超级管理员，全权限 | ✅ |
| 运营 | `operator` | 由 Boss 授权，管理特定模块 | ✅ |
| 守望者 | `watcher` | 普通玩家，参与游戏 | ❌ |
| 企业账号 | `enterprise` | 企业主账号，可查看旗下子账号数据 | ❌ |
| 企业子账号 | `watcher`（含企业归属）| 与守望者相同游戏权限，关联企业 | ❌ |

### 守望者等级

| 等级 | 标识 | 说明 |
|------|------|------|
| 🔵 初始守望者 | `initial` | 默认等级 |
| 🟡 进阶守望者 | `advanced` | 经人工审批升级 |
| 🔴 导师级守望者 | `mentor` | 最高等级，经人工审批 |

> **等级由运营人员手动审批，不自动计算。**
> 守望者通过前端"我的"页面申请升级 → 运营在后台审核。

## 2. 登录与访问

### 管理后台地址
访问部署地址 + 管理后台端口（默认与主服务分离），使用 Streamlit 界面。

### 登录方式

**方式一：手机号登录**
- 输入已注册的手机号
- 系统自动验证角色，只有 `boss` 和 `operator` 可登录

**方式二：开发者模式**
- 输入开发者密钥

### 退出登录
点击侧边栏底部"退出登录"按钮。

## 3. 卡牌管理

### 3.1 界面说明

卡牌管理页采用**图片式网格视图**，每张卡牌显示：
- **顶部**：安全类型（如"身体安全"）+ 适用阶段（如"启蒙期"）
- **中部**：事件描述文字（前60字）
- **底部**：分支徽章（🟢发布版 / 🔵测试版）+ 版本标签 + 状态标签

### 3.2 筛选功能

顶部工具栏可按以下维度筛选：
- **分支**：全部 / release（发布版）/ draft（测试版）
- **状态**：全部 / active（使用中）/ pending（待审核）/ approved（已通过）/ deleted（回收站）
- **安全类型**：身体安全 / 网络安全 / 心理安全 / 隐私安全 / 社会安全

### 3.3 卡牌状态流程

```
新建 → pending（待审核）→ approved（已通过）→ active（使用中）
                        ↘ deleted（驳回/下架）
```

### 3.4 新建卡牌

1. 点击顶部 **➕ 新建卡牌** 按钮
2. 填写：安全类型、阶段、事件描述、选项 A/B/C（文本 + 属性效果）
3. 点击"提交审核"→ 卡牌进入 `pending` 状态

### 3.5 审核卡牌

1. 筛选状态为"待审核"
2. 点击任意卡牌查看详情
3. 右侧面板中点击 **✅ 通过审核**（直接上线）

### 3.6 版本管理

**创建测试版（Draft）**
1. 选中一张发布版卡牌
2. 点击 **🔵 建测试版**
3. 系统自动复制当前内容为草稿，版本标签自动生成（如 `v20260228-测试版`）

**修改测试版**
1. 筛选分支为"draft"
2. 选中测试版卡牌 → 点击 ✏️ 编辑 → 修改内容 → 保存草稿

**发布上线**
1. 选中测试版卡牌
2. 点击 **🚀 发布上线**
3. 二次确认弹窗 → 再次点击确认
4. 测试版内容覆盖线上版本，原草稿自动归档

**查看版本历史**
选中卡牌 → 切换到"📜 版本历史" Tab → 时间线展示所有历史版本（只读）

### 3.7 批注功能

1. 选中卡牌 → 切换到"💬 备注" Tab
2. 在底部文本框填写优化建议
3. 点击"提交备注"
4. 备注以时间戳 + 内容形式保存，供团队参考
5. 备注以角标形式显示在卡牌上，点击角标可查看备注详情（/待做）

### 3.8 AI 生成卡牌

1. 滚动到页面底部，展开"✨ AI 卡牌生成器"
2. 输入主题（如"网络诈骗"）和详细描述
3. 点击"开始生成"（约 10-20 秒）
4. 在 JSON 编辑器中预览并可修改
5. 点击"提交审核"→ 进入待审核队列

## 4. 活动场次管理（/待确认）

### 4.1 概念说明

| 概念 | 说明 |
|------|------|
| **活动** | 一次线下活动，如"2025年春季安全培训" |
| **桌** | 活动中的一局游戏，由一名守望师主持 |
| **活动码** | 格式 `ACT-001`，守望师凭此码加入活动 |

### 4.2 创建活动

1. 进入"📅 活动管理"
2. 切换到"➕ 创建活动" Tab
3. 填写活动名称（必填）、主办方（选填）、时间（选填）
4. 点击"🎉 创建活动"
5. 系统自动生成活动码（如 `ACT-001`），**活动码线下告知守望师**

### 4.3 管理活动

**查看活动数据**
- 活动列表显示：桌数、参与人数、平均分
- 展开活动 → 查看各桌详情（桌号、守望师、得分、时间）

**归档活动**
- 活动结束后点击"🗄️ 归档"，活动进入归档状态
- 归档后玩家无法再用该活动码加入
- 可随时"🔄 重新激活"

### 4.4 守望师加入活动流程

1. 守望师启动游戏后，系统弹出"输入活动码"对话框
2. 输入运营提供的活动码（如 `ACT-001`）
3. 系统自动关联并分配桌号
4. 也可选择跳过，进行独立游戏

## 5. 用户管理与守望者等级

### 5.1 用户列表

**搜索**：支持手机号、守望师名、用户 ID 搜索

**列表字段说明**

| 字段 | 说明 |
|------|------|
| ID | 系统内部 ID |
| 守望师 | 守望师名（即游戏昵称）|
| 手机号 | 注册手机号 |
| 角色 | boss / 运营 / 守望者 / 企业 |
| 等级 | 🔵初始 / 🟡进阶 / 🔴导师 |
| 场次 | 参与游戏总局数 |
| 平均分 | 历次游戏平均得分 |

**用户详情**：点击用户后可展开游戏记录和关联 OSS 文件。

### 5.2 守望者等级审批（运营操作）

1. 切换到"📩 等级申请审核" Tab
2. 默认显示`pending`（待审核）申请列表
3. 查看申请人信息和申请理由
4. 填写审核备注（可选）
5. 点击 **✅ 通过** 或 **❌ 驳回**
   - 通过：用户等级自动更新，变更记录写入日志
   - 驳回：用户收到驳回通知（前端显示）

### 5.3 Boss 手动调整角色和等级

在用户详情页底部"⚡ Boss 操作"区域：

- **设置角色**：下拉选择 watcher / operator / boss / enterprise → 点击"更新角色"
- **设置等级**：下拉选择 initial / advanced / mentor，填写原因 → 点击"更新等级"
- **绑定企业**：输入企业账号 ID → 点击"绑定企业"（将守望者设为该企业子账号）

### 5.4 查看感想与反馈

切换到"💬 感想与反馈" Tab：
- 按类型筛选：全部 / 感想 / 问题反馈
- 勾选"只看未读"查看新消息（🔴 标记）
- 展开查看内容，点击"标记已读"

## 6. OSS 文件管理

### 6.1 三种视图

**📁 目录视图**（默认）
- 按 OSS 路径层级浏览
- 支持进入子目录和返回上级
- 显示文件名、大小、北京时间

**📅 活动视图**
- 按活动场次分组显示关联文件
- 匹配文件名中包含 `session_<id>` 的文件
- "独立游戏"分组收录未关联活动的文件

**👤 角色视图**
- 按守望师（用户）分组显示文件
- 匹配文件名中包含 `user_<id>` 的文件

### 6.2 删除文件

1. 点击文件行右侧"🗑️"按钮
2. 弹出确认提示
3. 点击"✅ 确认删除"
4. **注意：删除操作不可恢复，请谨慎操作**

## 7. 数据审计与分析

### 7.1 驾驶舱（核心指标）

**🎛️ 驾驶舱**页面展示：
- 用户总数、活跃用户数、总游戏场次
- 近期趋势图表

### 7.2 游戏分析

**🎮 游戏分析**包含三个 Tab：
- **核心指标**：每日活跃人数、得分分布
- **场次明细**：逐场次数据表，可按时间/模式筛选
- **卡牌分析**：各卡牌选择频率、选项分布

### 7.3 数据审计

**🧹 数据审计**支持逐场次人工审查：
- 查看场次详情（玩家、时长、得分、事件流）
- 标记异常场次（`flagged`）
- 批量执行自动审计规则

## 8. 系统设置与运营权限配置

### 8.1 系统参数管理

**⚙️ 系统设置 → 参数管理**：
- 查看、新增、修改系统配置（DEV_KEY、游戏模式、评分规则等）
- 敏感参数（Key/Secret）自动加密存储

### 8.2 运营权限配置（Boss 专用）

**⚙️ 系统设置 → 关于 → 运营权限配置**：

1. 前提：先在用户管理中将目标用户角色设置为 `operator`
2. 在运营账号列表中，勾选每个运营可访问的模块
3. 点击"💾 保存运营权限配置"即时生效

**可配置模块**：（/待完善，需要更细致的权限控制）

| 模块 | 说明 |
|------|------|
| 👤 用户管理 | 查看用户列表、审核等级申请、查看反馈 |
| 🎴 卡牌管理 | 增删改卡牌、审核、版本管理、批注 |
| 📅 活动管理 | 创建/管理活动场次 |
| 📂 OSS 管理 | 浏览和删除 OSS 文件 |
| 🧹 数据审计/分析 | 查看数据分析和审计记录 |

> 运营无法访问系统设置和运营权限配置页面（Boss 专用）。

## 9. 常见问题 FAQ

**Q: 运营登录时提示"访问被拒绝"**
A: 该手机号对应的账号角色不是 boss 或 operator。请让 Boss 在用户管理中将角色更新为 `operator`。

**Q: 创建活动后活动码是什么格式？**
A: 自动生成，格式为 `ACT-001`（三位递增数字）。创建后在活动列表中查看。

**Q: 守望者提交升级申请后在哪里审核？**
A: 用户管理 → "📩 等级申请审核" Tab → 筛选 `pending` 状态。

**Q: 卡牌测试版发布后，原来的线上版本还在吗？**
A: 测试版发布会覆盖线上版本内容，但原版本内容保留在版本历史中，可随时查看（只读）。

**Q: OSS 文件删除后能恢复吗？**
A: 不能。OSS 删除操作不可逆，请谨慎操作。建议删除前确认文件不再需要。

**Q: 游戏数据中的"场次"和"活动"有什么区别？**
A: 一局游戏 = 一个场次（session）。活动是多个场次的集合，代表一次线下培训活动。一次活动可以包含多桌（多个场次）。

**Q: 企业账号如何查看子账号数据？**
A: 企业账号登录玩家端（非管理后台），在"我的"页面可查看旗下子账号的活动参与情况和得分汇总。如需详细数据，联系 Boss 通过管理后台查看。

**Q: 如何更改开发者密钥（DEV_KEY）？**
A: 系统设置 → 参数管理 → 找到 `DEV_KEY` → 点击编辑 → 填写新密钥 → 保存。
