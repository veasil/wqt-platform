# Platform 基线地图：当前实现、历史发布与后续接入

核对日期：2026-11-13；源码依据：协作快照 `b469661`。本文后续更新仅整理配置和交接，不汇入其他发布分支代码。线上当前状态本轮未探测。

## 名称不能代替版本

| 名称 | 实际对应 | Emma 应如何使用 |
|---|---|---|
| wqt-platform | 一个 Express 单体仓库，含共享平台能力和多套前端 | clone 完整仓库，不复制一份后端到课件里 |
| 新版玩家前端 | `public/player/`，入口 `/player/` | 参考调用和状态恢复；保留原入口 |
| 旧版玩家前端 | `public/index.html` 等，入口 `/` | 兼容代码，不作为新课件接入首选 |
| 平台 / 组织管理前端 | `admin-web/`、`enterprise-panel/` | 用于管理；不能把管理员登录桥接当成公开接入 |
| 新版账号后端 | `src/platform/accounts/`，`WQT_ACCOUNT_MODEL=accounts` | 身份、账号、组织分离，Redis 会话；同时启用新版玩家路由 |
| 旧账号模式 | `WQT_ACCOUNT_MODEL=legacy` 或未设置 | 新版玩家 API 不注册；看到 HTML 不代表 API 可用 |
| 新版桌游后端 | `src/game/player/`、共享 `src/game/sessions/` | 是同一后端中的模块，不是另一个 SDK 服务 |
| 旧管理后台 | `admin-panel/` Streamlit | 历史参考，不作为新开发入口 |

平台不是通用任意积分账本：当前积分由场次、卡组、伍力状态及结算规则定义。课件交互可以替换界面，不能自行替换数据来源和权限规则。

## 课件代码放在哪里

建议首份待评审样例放 `examples/courseware/emma/`，附 README（入口、运行方式、平台基线 SHA、素材来源、测试状态）。这是建议位置，当前还没有课件、构建脚本或自动托管规则。不要把整站、node_modules、客户素材、真实学员记录和凭据一起导入。

该位置不会由 Express 自动公开，先使用本地静态开发服务或 API 替身。若未来确定由平台同源托管，再单独设计托管路径；若仍部署在 Emma 的独立网站，可把完整站点留在自己的仓库，平台库只保留最小集成样例及必要接口改动。**代码放在同一仓库、运行在同一域名、使用同一登录身份是三个不同决定。**
