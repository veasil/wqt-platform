## 一、新规则视频：开玩前 3 分钟，让孩子看懂怎么玩

### 这是给谁看的
2026 版全新规则解说视频已上线，**每场活动正式开玩前播放给全场看**——替代了旧版的幻灯片讲解，孩子看一遍就能上手，不用大人干讲半天。3 分钟，专为儿童注意力设计，放完直接进游戏。

### 视频里讲了什么

**🔹 五力 = RASPE**
桌游核心是"五力"，视频用卡片特写逐一讲清五力是什么、对应什么颜色：
- **R · 安全力**（蓝）
- **A · 脑波力**（红）
- **S · 实感力**（黄）
- **P · 创心力**（绿）
- **E · 沟通力**（紫）

记法就是口号：**「Give Me Five — RASPE Power Up!」**（RASPE 里的 PE 念 /piː/，朗朗上口，孩子喊一遍就记住）。

**🔹 伍力守护团 = 小伍大脑里的驾驶员**
这是新版最关键的概念补强。用《头脑特工队》里飞船驾驶员式的比喻，讲清"守护团"就是给主角小伍出主意的小伙伴——孩子一看就懂游戏里"五力"是怎么被调动起来的，不再觉得抽象。

**🔹 三条新规则动效**
视频用动画演示了三条最容易讲糊的规则：
- **点赞贴纸能量**——怎么攒、怎么用；
- **数智技能**——拿五力贴纸贴到通关卡上可 +1 分，全场每场限用一次；
- **通关卡四步 + 手印仪式**——通关的完整流程和最后的仪式感。

### 什么时候放
**每场活动开玩前**，全场孩子和家长一起看。3 分钟放完，趁热直接开局——孩子注意力正好在峰值，规则也记得最牢，别在中间插大人讲解打断节奏。

### 怎么拿到视频
视频文件由**运营或活动组织者统一分发**（文件名以实际发放为准，最新成片持续更新中）。守望者拿到后，现场用投影或大屏播放即可；想自己留存或回看，向你的活动对接人索取一份。

### 小贴士
- 👉 **别跳过视频直接开局**——3 分钟是专门为孩子注意力设计的，比大人嘴讲规则高效得多，也省得你嗓子冒烟。
- 👉 第一次带孩子玩的家长，建议自己也完整看一遍，这样玩的时候能接住孩子"五力是啥"的提问。
- 👉 视频里的"五力 RASPE"和通关后**复盘报告**里的"伍力召唤"雷达是同一套——看完视频再看报告，完全对得上。
- 👉 现场投影记得提前调好音量，视频有配音和背景音乐，音量太低孩子容易分神。

## 二、守望学习：开局前，先把卡牌看明白

### 这是什么
「守望学习」是你作为守望者的**预习资料库**。游戏里每一张卡牌——孩子会遇到什么情境、有哪些选项、每个选项会带来什么后果、五力（安全力 / 脑波力 / 实感力 / 创心力 / 沟通力）怎么变化——在这里都能提前看到，还配了卡面图、白皮书索引、导师带领笔记和补充案例。

简单说：**游戏是考卷，守望学习是答案解析。** 你先看懂了，带孩子玩的时候就能引导得更有方向，而不是跟着孩子一起懵。

### 在哪找到它
1. 打开首页，点右下角进入 **个人中心**；
2. 顶部标签栏选 **「守望学习」**；
3. 进入后会看到当前卡牌组的全部卡牌网格，顶部可按安全类型筛选。

### 怎么用
- **筛选**：点顶部的安全类型下拉，只看某一类（比如只想复习"身体安全"相关卡牌）。
- **看卡牌**：网格里每张卡显示卡面缩略图、卡牌编号和安全类型，点开任意一张进入详情。
- **翻页阅读**：详情页是左右滑动的翻页式——
  - **第 1 页**：卡面大图 + 情境描述 + 全部选项一览；
  - **第 2～N 页**：每个选项单独一页，写清「做法 / 后果 / 五力影响 / 评分理由」，五力用绿（加分）、红（减分）色标一目了然；
  - **末页**：延伸学习——子主题、白皮书索引、导师索引、带领笔记、补充案例、引导语、属性总说明。
- **翻页**：用左右箭头或底部的圆点指示器，也支持直接横滑。

### 小贴士
- 👉 **建议每次换新卡组后先来这里翻一遍**，尤其留意孩子上次选错的卡，看看"本可以怎么选"。
- 👉 守望学习是**会员权益**。如果有效期到期或被停用，会提示"🔒 守望学习为会员权益，开通/续费后即可使用"——续费后即刻恢复。
- 👉 带领笔记和补充案例特别适合第一次带孩子玩的家长，等于一份现成的"主持词"。

## 三、切换卡牌组：左上角菜单，一秒切到对的那副牌

### 为什么要在意卡牌组
游戏里有不止一副牌，**不同场合该用不同版本**，选错了活动的"调性"就不对：
- **2026 版卡牌**（今年精选）→ **标准活动用这副**，也是系统默认；
- **2025 版卡牌** → **公益活动用这副**，内容更基础、门槛更低，适合第一次接触的孩子和临时场次。

选对卡牌组 = 选对了这一桌的难度和主题。第一次进游戏默认就是 2026 版，平时不用管它；只有办公益活动、想用回 2025 版时才需要手动切。

### 在哪切换
1. 在首页**看向左上角**，有一个汉堡图标按钮（☰，鼠标悬停提示"选择卡牌组"）；
2. **点一下**，从顶部滑下一个「选择卡牌组」抽屉；
3. 抽屉里列出所有可选卡牌组，每行写明名称、张数，带「默认」标签的就是当前系统默认那副（2026 版）；
4. **点你想用的那一组**即可。

### 切换会发生什么
- 选中的组会高亮，抽屉自动关闭，页面刷新；
- 切换后**这副牌会在整局游戏里生效**，新开张卡牌都来自这个组；
- 守望学习里看到的卡牌也会跟着变成这组的卡（个人中心 → 守望学习 同步切换）。
- ⚠️ **如果游戏已经开局**，系统会弹窗提醒"切换卡牌组将重置当前游戏，确定切换吗？"——开局后想换牌会清空当前进度，请开局前先切好。

### 不选会怎样
什么都不点、直接开局也没关系——系统会自动用带「默认」标签的那副（即 2026 精选版），不会出现"没牌可玩"的情况。

### 小贴士
- 👉 **办公益活动**：左上角切到「2025 版」再开局。
- 👉 **办标准活动 / 日常带娃**：保持「2026 版」默认即可，不用动。
- 👉 不确定当前用的是哪副？左上角点开抽屉，高亮的那行就是当前组；或者开局后复盘报告的"信息条"里也会标注本局卡牌版本。
- 👉 卡牌组是按"场次"生效的，切完这局用完就行，下一场想换另一副再切。
- 👉 选择只记在当前标签页里，不会影响你别的设备或别的标签页，各玩各的。

## 四、活动码提前申请：别等开桌了才手忙脚乱

### 为什么要提前申请
一场线下活动（社区专场、亲子局、夏令营）往往要开好几桌，**每桌开局都要绑定一个活动码**。活动码不是现场能即时生成的——它需要运营审核。提前申请，能保证你到现场时活动码已经就绪，孩子和家长们落座就能开局，不用干等。

活动码长这样：**ACT-00X**（例如 ACT-007）。

### 在哪申请
1. 进入 **个人中心** → 顶部标签选 **「活动」**；
2. 上半部分是「开启活动」表单，下半部分是「我发起的活动」列表和「查询活动」。

> 也有一个独立的活动管理页（`activity.html`），功能一致，工作人员也会在这里直接创建活动；守望者走"申请"流程即可。

### 申请步骤
1. 在「开启活动」表单里填：
   - **活动名称**（必填，例如"暑期社区亲子安全专场"）；
   - **地点 / 主办**（选填，例如"XX 社区中心"）；
2. 点 **「提交申请」**，系统提示"申请已提交，请等待运营审核"；
3. 申请进入「我发起的活动」列表，状态显示为 **待审核**；
4. 运营审核通过后，状态变成 **已通过**，活动码（ACT-00X）会显示出来，旁边有 **「复制」** 按钮——点一下即可复制到剪贴板。

### 状态怎么看
| 状态 | 含义 |
|------|------|
| 🟡 待审核 | 刚提交，等运营审 |
| 🟢 已通过 | 活动码可用，可以复制去开局了 |
| 🔴 已驳回 | 运营没通过，通常会有原因，可联系运营 |
| 🟡 已结束 | 活动已结束（不再支持新开桌） |
| ⚪ 已归档 | 历史活动，仅留档查看 |

### 现场怎么用活动码
- 把活动码报给每一桌的守望师，开局时在游戏里绑定即可（一桌一码，多桌共用同一活动码也没关系，系统会按桌号区分成绩）；
- 列表里会显示该活动已有 **多少桌** 开过局，方便你掌握现场进度。

### 赛后查询
活动结束后想看各桌成绩？同一页下面的「查询活动」里输入活动码 →
- 显示活动名称、主办、活动码、参与桌数；
- 列出每一桌的守望师名和最终得分。

### 小贴士
- 👉 **至少提前 2–3 天申请**，给运营审核留时间，别活动当天才提交。
- 👉 一场活动可以多次复用同一个活动码，**不必每开一桌都重新申请**。
- 👉 活动码记不住没关系——「我发起的活动」列表里随时能复制。
- 👉 想办多场不同主题的活动？每场各申请一个码，赛后按码分别查成绩，数据不会混。

## 五、新复盘报告介绍：通关之后，一张能发朋友圈的海报

### 全新海报化改版
这一版复盘报告**彻底重做了版式**——从过去一段纯文字总结，升级成一张可分享、可打印的"成长评估海报"。配色对齐品牌 IP「小伍」（蓝紫科技风），闯关故事还配了 AI 生成的插画，画风统一温暖。

### 在哪点复盘
- **首页底部「复盘」按钮**（和「新游戏」「暂停」并排的那个）；
- **提前结束游戏时会自动弹出复盘**（点首页"结束"按钮 → 确认后自动开生成）；
- 通关后也可以随时点「复盘」生成。

### 报告里有什么（五大板块）
海报从上到下依次是：

**🔹 顶部品牌横幅**
"AI 在 5000 天 · 数智免疫力 · 伍力全开" + 大标题《小伍5000天数智成长评估报告》+ 副标题"桌游单轮复盘阅读版"。

**🔹 信息条**
闯关日期、玩家构成（如"启蒙期 2 人，成长期 1 人"）、成长阶段、本局卡牌版本、综合得分率（百分制）。

**🔹 本轮卡牌条带**
横向展示这一局玩过的全部卡面缩略图（共 N 张），标注本局用的是哪一版卡牌。**点任意卡面可放大查看**。

**🔸 01 本轮总览**
2–3 句话讲清"小伍这轮经历了什么"，外加一句话结论（黄色高亮框）。

**🔸 02 风险遭遇（雷达图）**
五边形雷达，按"身体 / 心理 / 社交 / 经济 / 社会"五类安全，展示这一轮各类风险出现的强度，附一句点评。

**🔸 03 伍力召唤（雷达图）**
五边形雷达，按五力（安全力 / 脑波力 / 实感力 / 创心力 / 沟通力）展示实际调动情况，附一句点评。

**🔸 04 闯关故事**
报告的核心。8–14 段、1500 字以上的成长故事，按出牌顺序逐关展开——交代情境、小伍怎么想、选了什么、后果如何、五力具体怎么变。**故事里穿插 3 张 AI 生成的插画**，画的是这一轮里最惊险、最纠结、最关键的三个瞬间。文末附 3 条"成长小贴士"。

**🔸 05 数智行动公约**
4 条第一人称的"我会……"行动公约，把游戏经验带回真实生活；最后一条"带回家的一句话"，送给家长对孩子说。

**🔹 底部品牌横幅**
官方 logo + 公众号二维码 + 小伍三个成长阶段（2–5 岁 / 6–11 岁 / 12–15 岁）的形象，扫码即可关注。

### 生成过程（分段进度条）
点「复盘」后，画面会显示一条**进度条**，告诉你现在跑到哪一步——不再是干等一段文字：

| 进度 | 阶段 |
|------|------|
| 12% | 分析本轮闯关数据 |
| 45% | 汇总伍力与风险雷达 |
| 55% | 用生图模型绘制 3 张闯关故事插画 |
| 85% | 准备卡面与品牌素材 |
| 92% | 排版生成海报 |
| 94% | 上传报告 |
| 100% | 完成 ✅ |

整个生成大概需要几十秒（主要花在 AI 画那 3 张插画上），耐心等进度条跑完即可。

### 导出与分享
报告生成后会出现一个卡片，写着"🎉 复盘报告已生成"和一句话结论。点 **「📄 查看 / 导出海报报告」** 打开报告页，底部有两个按钮：
- **📥 导出为图片**：一键把整张海报导出成 PNG（用浏览器截图技术），文件名形如`小伍数智成长复盘_2026-07-01.png`，**直接发朋友圈、发家长群都没问题**；
- **🖨️ 打印 / 存 PDF**：调起浏览器打印，可存成 PDF 留档。

### 小贴士
- 👉 **至少要打满一定张数的卡牌才能生成有意义的复盘**（默认 7 张，运营可在后台调整这个门槛）。卡太少时系统会提示"数据不足"，再玩几张就行。
- 👉 AI 插画依赖文生图服务。**极少数情况下该服务未开启或临时不可用**，报告会自动跳过插画、照常生成其余内容，不会卡住你——只是故事段少几张配图。
- 👉 故事里主角统一叫"小伍"，并且**严格遵守"不虚构"铁律**——只写这一局真实发生过的卡牌情境和角色，不会凭空冒出卡牌里没有的人物或情节，可以放心给孩子看。
- 👉 每个浏览器标签页的对局是**相互隔离的**，你开多个标签页分别打局，复盘不会串号。
- 👉 报告生成后会上传云端存档；即便上传失败，也会回退到本地文件，**不会丢**。
