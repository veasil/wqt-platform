# 玩家端故障说明与分级

状态：本地实现完成，2026-10-29 继续复核；待用户验收，未发布。来源：2026-10-28 本聊天，用户忘记 length 触发步骤，明确要求优化 JS 故障并给出故障说明、分级理解和重要性判断。关联前序 [导出与恢复](robustness-20261028.md)。

## 边界与判断

产品目标：故障时能知道影响什么、是否需要核对提交、如何继续，并能提供最小定位信息。错误类型用于定位原因，影响级别用于安排处理；二者分别表达。分级是客户端初步判断，不代表已经证明服务宕机、数据丢失或安全事故。

| 级别 | 含义与处理 | 客户端可判断的例子 |
|---|---|---|
| P0 紧急事故 | 经核实的数据损坏、越权或广泛不可用，需要负责人立即处理 | 浏览器单次异常不能自动认定；本轮不自动赋值 P0 |
| P1 优先核对 | 写入结果未知，或未被局部边界接住的运行异常；先核对结果，再决定恢复操作 | 计分提交超时；全局未捕获 JS 异常。不能据此认定提交失败或所有用户受影响 |
| P2 局部故障 | 当前读取/局部功能受阻，存在重试或替代路径 | 普通读取连接失败、服务 5xx、已捕获 JS/响应格式异常、图片导出失败 |
| P3 操作提示 | 预期的输入、身份、权限、频率或状态限制，先按提示处理 | 输入缺失、登录失效、权益不足、版本冲突、429；通常不立为代码事故 |

当前迭代决定：玩家端统一分类/说明，API 响应解析失败在边界显式报错；保留写入结果未知语义与原有去重恢复。原始 length 没有调用栈，仍待复现，不因用户忘记就标记已修复。

明确延后：第三方监控、远程日志上报、数据库故障表、自动停服/回滚、跨用户聚合与自动事故升级。没有数据采集/权限/认证/生产网络边界变更。仅在当前页面展示与复制最小诊断摘要，不在 storage 持久保存、不自动上传。JS 在 HTML 加载前无法处理浏览器 ERR_CONNECTION_RESET，网络层原因仍需现场证据。

## 验收与实现计划

1. 用户看到可理解的状态；“故障说明”展开后包含类型、影响、恢复建议、固定故障代码及本次参考号。原始 stack/属性名不直接展示。
2. 区分局部降级、程序异常和业务提示；写入的网络失败/5xx/无效成功响应明确“结果待确认”，不自动重新提交。
3. API 成功响应非 JSON/空内容不再降为 `{}`；关键反馈数组与卡牌数组在赋值前验证，异常保留原状态。
4. 玩家端捕获事件处理器外的 error/unhandledrejection，给出说明并保留页面；不删除录音、不重载页面、不伪装执行成功。
5. 可复制摘要仅含本次参考号、固定故障代码、等级、时间、受控页面名、来源、HTTP 状态和请求方法；不包含 token、账号/场次 ID、请求体、URL/query、异常原文或栈。剪贴板不可用时仍可手动复制。
6. 导出报告自带局部故障说明，失败不影响原报告，沿用手动保存/PDF路径。
7. 自动测试涵盖分类、请求协议错误、写入结果未知、不触发自动重试、全局边界、复制摘要与敏感数据排除；合成数据，不连接业务库或外部供应商。

不涉及 schema 迁移。回退为还原本次 errors/api/player 与报告说明代码，保留既有报告与业务数据。

## 实现结果

- `public/player/errors.js` 提供类型/影响分级、恢复文案、白名单诊断摘要和可展开说明。P0 不由单个浏览器事件自动认定；无标签的普通 Error 保守记为 P2 待定位，避免误认为正常业务提示。明确的 4xx、已标记的本地校验/取消才按 P3 处理。
- `public/player/api.js` 显式拒绝无效成功 JSON/非对象结果；记录请求方法与写入结果是否未知。连接错误保留原始 cause。取消前已中止的请求不发送；不新增自动重试。写入收到 2xx 后解析失败、连接中断、408/5xx 时，按结果待确认处理。
- `player.js` 为已有局部边界和全局 error/unhandledrejection 展示说明；没有原提示位置时使用可收起通知。反馈和卡牌数组验证后才赋值，错误响应保留当前数据。原有去重编号、未确认操作和录音恢复逻辑继续保留。
- `public/game-review.js` 的下载报告在导出失败时显示 P2 故障说明与 PDF 替代路径，恢复成功后收起说明。

## 工程复核

新发现的约束：成功 HTTP 状态不保证响应能解析；提交后看不到确认不保证服务器未保存。故障说明与自动重发相互独立，写入结果不明确时保留原操作编号，先核对。

新增维护成本：故障代码、说明和实际恢复入口需同步维护。参考号仅关联当前页面的控制台记录，不是可在服务端查询的追踪 ID；页面关闭后本地诊断可能丢失。远程聚合监控、重复错误频率统计、自动事故升级继续延后。

未定位事项：用户原始 Safari length 异常仍缺触发步骤和调用栈；本轮不能承诺所有 JS bug 已消除。真实 Mac Safari 验收、UNSDG 网络原因、GitHub PR/合并与生产发布仍未完成。本轮没有生产配置或 schema 更新。
