## 版本与限制

- 基线 HEAD `2686609`，分支 `codex/account-permissions`。该分支在开始前已有大量在制改动，本任务仅追加功能差异，未暂存或提交既有改动。以上为工作区证据，不是干净提交的 CI 结果。
- 生产环境未连接、未迁移、未发布；新旧 schema 兼容和并发已在合成独占库验证，目标业务库的存量盘点与发布演练仍属于发布工作。
- 实现面向新版 `/player/` 和账号模型。旧版兼容 HTML 未同步改造；旧认证模型的活动关联限制保留。
- 地点以文本为准，不使用定位或地址模糊匹配；同地点的不同写法不会合并。人工/历史活动不猜测归并，需主动使用其活动码。
- 反馈读取最近 200 条通用意见及最近 200 条问卷；运营回复、跨账号汇总及分页不在本次范围。通用反馈的“已查看”沿用既有状态，问卷查看展示当时保存的题目与答案。

## 失败、修复与重验

- 新隔离用例最初清理方法名称错误，且合成过期体验违反已有起止时间约束；改用 runtime.stop 并构造合法过期区间。问卷表无 id，插入显式 RETURNING session_id。均为测试夹具问题，修正后新集成用例通过。
- 旧浏览器回归曾断言旧文案并等待默认可见的活动码表单；按新交互改为展开后输入、等待跳过入口。旧完整游戏用例同样先展开码入口；修改后原回归和完整游戏集成均通过。

## 工程复核

- 改变的假设：活动可以跨组织归集；体验开局不再依赖活动码。没有把活动归集等同于场次权限共享。
- 新约束：自动活动唯一键为 UTC+8 日＋地点；活动归首次成功创建者组织，各桌归属不变。事务锁防止两人同时查询到“无活动”而重复创建，唯一索引提供数据库兜底；活动行锁防止重复桌号。
- 保证：场次、关联及幂等记录原子提交，失败整体回滚；后端实时权益与绑定校验继续生效。已提交问卷以保存的题目快照展示，避免题目配置变化造成旧答案错位。
- 新增成本：两个可空字段、一个索引；更长的内部随机活动码默认隐藏。未引入队列、定位服务或通用匹配框架。
- 文档：spec/plan、本证据及领域规则已更新。延期事项：地址标准化、更细时间窗口、运营回复、旧版页面迁移及生产发布。
