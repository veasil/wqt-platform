## 回退

新增 `activities.auto_day`、`auto_location` 可空文本字段及二者的部分唯一索引，旧行均保持 NULL，不按现成员关系回填、不更新场次归属。只在账号模型初始化时执行增量迁移。历史自动归并歧义通过不回填避免。

同日同地点的创建由 PostgreSQL 事务级 advisory lock 串行化，唯一索引额外阻止重复键；活动行锁串行分配桌号，创建场次、关联、幂等结果同一事务提交。失败时一起回滚。

生产发布前必须在目标库做独立 schema 盘点（确认不存在同名冲突字段/索引）及迁移演练，本任务只验证随机独占合成库；未触碰业务库。自动活动使用随机内部编码，前端按需显示。

回退：恢复本次功能前应用版本，保留新字段、索引和已经生成的活动/关联，避免删除运行数据；回退后新功能入口及跨组织关联停止，已有场次仍按原账号读取。不要直接删除活动或猜测拆分已经合并的数据。恢复新版本可以继续使用现有自动键。不可用 git restore 覆盖既有在制改动。
