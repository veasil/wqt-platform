# WQT-004 · 启动保护与完整 schema 合成数据

状态：执行中。来源：需求方 2026-09-12 明确“先补启动保护，准备合成数据，然后按顺序落地”。
基线：d6b4c1d，依赖 WQT-003 / PR #5（尚未验收合并）。分支 codex/staging-startup-guards。

## 目标与范围

数据库初始化写入前验证部署配置与只读配置盘点；禁止部署环境的模拟/固定验证码回退；在完整应用 schema 中准备可复用合成数据；CI 覆盖与生产镜像一致的 PG18，并保留 PG16。

## 非目标

不直接部署生产，不复制真实用户数据，不购买未确认预算的资源。生产触发器关闭与首月$9采购已由后续gate明确批准，执行记录见cloud-gates.md。预发布搭建后才执行真实外部服务验证，不以配置存在证明短信/OSS可用。

## 验收标准

| ID | 标准 | 证据 |
|---|---|---|
| AC-01 | 非开发/测试环境须显式 production、SERVER_ENV、强密钥与两个数据库连接，禁止登录捷径 | 无数据库测试、启动拒绝子进程 |
| AC-02 | staging 目标与预期 host/database/bucket 一致，拒绝副本敏感配置；检查发生在 initDb/迁移前 | 独占 PG，检查污染拒绝后 users/game_sessions 仍不存在 |
| AC-03 | 生产缺短信配置不返回 mockCode，固定验证码不能通过 | 生产模式隔离子进程 |
| AC-04 | 完整 schema 创建组织A/B、管理员/成员/个人、固定/个人/未知场次；非空拒绝、失败回滚、不伪造外部文件 | 合成数据 PG 场景 |
| AC-05 | PG16/18 与浏览器 CI 通过；部署前配置/生产触发器/采购 gate 分别记录 | CI 与操作材料 |

## 确认与验收

上述实现属于需求方已确认的启动保护与合成数据范围。云端采购需要预算和准确报价；生产触发器变更及正式发布属于重要 gate。尚未完成本轮最终验收。
