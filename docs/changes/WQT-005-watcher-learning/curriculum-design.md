# 守望者课程体系 · 教学设计草案

日期：2026-10-16。依据用户本轮定义、SW-L07伍力SKA和SW-L08—12白皮书目录。对象为守望者，目标是提高家庭观察、陪伴、带领和协商能力，而非让孩子独自自学。课程标题、目标与练习为本轮设计，不代表原资料中已有同名课程或完整讲义。

## 设计原则

- 每条路径围绕概念—家庭作用—观察与方法—实践复盘；从理解到可观察的行为变化。
- 安全力覆盖五大白皮书目录的28个风险议题；其余能力是跨风险的支持能力，不做五力与五风险一一映射。
- 脑波力讲注意力、情绪与作息支持，不把术语解释为可测脑波训练或疗效；不把守望者当作医生/心理治疗者。
- 创心力沿用已确认品牌名，对应用户说的创新力：内在动机、真实需要、设计思维和创客营带领。现有SKA是规划依据；完整创客营既有课件仍需补充，不能冒充已迁移整套内容。
- 沟通力是守望者的家庭关系支持能力：表达、倾听、协商、修复与求助，不能只做儿童演讲训练。
- PPT用于结构讲解、图文用于阅读与练习、视频用于示范；format是建议呈现方式，不是已有文件类型。没有PPT就显示制作中。
- 各课评估以能否描述具体事实、完成一次实践、说清复盘与边界为依据；未设定未经验证的学时、认证或疗效。

## 资料核对范围

已下载原始资料，读取SKA正文及五本白皮书目录。白皮书部分正文字体映射异常，未宣称全文转换/校对完成；原文中的医疗、法律、神经科学论断在正式课程编写时仍需核验。安全力以下为课程议题规划，不直接提供临床或法律处置指南。

## 模块与课程

- 概念：理解守望者的角色、共同语言与基本方法。

- 学习结果：能说明守望者的责任边界，并找到合适的基础资料。
