空间以“看见儿童，也看见技术环境”为出发点。倾斜的矩形窗口呼应现有公司标识的方向感，以三重边界、局部穿透和有节制的连接，表现支持、成长与共治之间的关系。每一条线的偏移、每一层间距都保持精确；图形的力量来自重复与比例，而非堆叠装饰。

色彩从原有材料中生长。提取公司简洁标识的主色 #337CFF，配合深靛蓝、白色与少量温暖橙色。蓝表达技术与行动，橙把注意力带回人的参与，深色给系统与判断以稳定感。明暗场景共享身份，材质只在需要强调支持边界时出现。颜色比例和文字对比经过逐项检查，不让亮色成为阅读障碍。

文字用清楚的中文重量建立秩序，英文只承担索引与补充。企业定位、计划名称、产品名称各有尺寸与落点。版面的精度体现在行长、留白、基线和重复位置：大字表达主张，小字承载出处，图形让关系可见。让专业判断通过编辑和排版被感知。

人物和 IP 保留其独有角色。小伍属于体验与行动的邀请，企业标识承担组织身份，计划徽章承担项目识别。不同层次通过署名和间距相连，不靠混合出新的复杂 Logo 来表达“统一”。现有资产保持原貌，新辅助图形明确标为候选；表达强度随触点调整，结构持续一致。

动作从“预演—激活—形成”的逻辑中获得节奏：先出现边界，再让内容进入，最后稳定为可阅读状态。位移短、反馈及时、可以中断；减少动态效果时内容直接成立。精修应持续减少无用细节，把注意力集中到真正的品牌资产、真实内容与人的成长。

- 企业叙事以《产品官方介绍》revision 86 中的公司最终版和产品状态为工作依据。

- 蓝色以原始 PNG 非透明像素中的最高频值 #337CFF 作为采样基准；其余色值为本轮设计建议，不声称现有标准。
- 教育支持、成长支持、技术治理采用当前原文的三系列结构。产品状态原文保留，未把测试产品呈现成已交付商业能力。

- 合作、报告、海报与名片均为应用样张；不填造客户、数据、资质、个人联系方式和真实测评成绩。
