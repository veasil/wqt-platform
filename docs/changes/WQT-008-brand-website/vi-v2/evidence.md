## 迭代调整

1. 从原始项目介绍中直接提取简洁公司标识，不重新描绘，提取主色最高频像素 #337CFF。
2. “共益之窗”呼应现有斜向标识，定义为辅助图形。计划/产品单独署名，不用新图形替换它们。
3. 三系列以当前官方结构区分，沿用折页中的蓝/紫/橙线索。教育系列和行动按钮使用较深蓝色承载小白字，治理橙使用深文字。
4. 第一轮封面的英文标注与图形/数字局部重叠，精修时删除冗余标注，保留主张和原公司标识。
5. 现有五力和体系数字存在版本差异，本轮写完整系列/能力内容，不擅自确定最终编号。
