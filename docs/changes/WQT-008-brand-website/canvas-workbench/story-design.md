# 品牌故事与插画系统

来源：2026-10-14 用户要求讲品牌历程与多维故事；从 AI 时代、风险、素养、家庭陪伴、多方共建，展开调研、活动、产品、行业、培育、传播，连接未来生态。按故事生成更多插画，并统一成熟的设计语言。

## 叙事

时代与社会 → 风险命题 → 素养提升 → 家庭陪伴 → 多方共建 → 六类品牌行动 → 未来生态。每章说明问题、品牌回应及与下一章的关系，具体文案与来源见 story-chapters.json。

主张沿用原三折页“让儿童友好成为 AI 产品的真‘芯’”。公司覆盖教育支持、成长支持和技术治理；故事不收缩成单一桌游宣传。

品牌历程单独设证据板：历史项目介绍第 7 页记录 2022 报告、2023 ICC 项目启动、2024 欧盟报告参照、2025 平台青少年模式评估及体系探索。上述均标注“项目材料记载”，不把欧盟报告当作公司发布，不推断公司成立年份，不延用旧体系编号作为当前标准。当前产品系列及状态依 S1/S2。

历史项目介绍第 25 页同时保存了 2023 全球发明大会现场体验、教育蓝图论坛、ESGforKIDs 专家研讨，2024 郑州交流与中国儿童幼教展，2025 新加坡论坛计划发布的原始图文。历程板链接这些实际材料，不用新插画冒充历史现场。

## 统一的插画语言

成熟的叙事型 3D 编辑插画，直接参考飞书原倡导海报的柔和立体动画语言、蓝紫渐变、白蓝机器人与流动光带。成人与学龄儿童的年龄关系清楚，不把青少年画成幼儿；保留原图适度风格化的面部比例。孩子有行动和表达能力，成人倾听与协作；机器人只在适用场景作辅助，不替代人与陪伴。首张偏写实测试另存，不作为母版。

配色以标识蓝 #354AAD、电蓝 #337CFF、深蓝 #111D42、冰白、淡紫和少量金色 #DEB657 为主。磨砂玻璃、少量透明蓝色构件、真实日常材料结合；统一柔和方向光与相近镜头高度。复杂场景以清楚的人物关系和单一叙事焦点组织，不把所有物体做成发光 UI。

保持已有蓝色光流、轨道和金色强调的识别，降低装饰在主体场景中的比重。12 张独立 3:2 横版插画采用同一色彩、比例、材质和光线规格。画内不生成文字、Logo、统计、评级与证书，中文与原有标识在排版层添加。

成熟的设计系统还包含：稳定中文字级、标题/正文/证据层次、统一网格、图文比例、图像留白和源文件规范。故事板以真实内容组织；来源与制作状态置于评审层。

## 事实与状态

S2 公司三折页已由用户确认为真实业务事实；S1 为已读官方介绍。S4 用于历史记载与理念，不把其预测转成当前成绩。新插画表现业务类型和愿景，不是活动照片或真实客户证明。

新画面为候选，不修改已认可的产品技能或原始标识。旧图、组件及历史方案保留在白板中，本次故事与插画置顶。交付前检查主体、比例、完整性、风格一致性、构图与文字布局；用户保留最终品牌表达和审美验收。
