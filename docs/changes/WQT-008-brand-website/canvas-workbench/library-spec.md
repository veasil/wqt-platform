# 品牌素材与组件候选库 · 制作范围

来源：2026-10-14 当前会话。用户要求继续完成素材与 UI，确认公司三折页是真实业务事实，并强调善用生图模型。沿用已有标识、角色和三折页的视觉，不另立大概念。

## 交付范围

- 生图：横版科技背景、竖版活动背景、浅色研究背景、金色手绘装饰、蓝色轨道装饰、儿童与技术陪伴插画。独立文件；透明装饰保留真实 alpha。生成结果逐项记录，失败不计入完成数。
- 矢量：四大切面、五类风险、三大系列、三步干预逻辑、五力和通用操作，28 个独立图标。分类独立，不暗示风险与能力一一对应。
- 容器：产品玻璃语言的卡面、横幅、面板，分别提供亮/暗独立 SVG。控制角部像素尺寸，避免通用拉伸。
- 基础 VI 候选：现有身份与组合、颜色职责和字级。保留徽章版本差异，不自行定唯一公司标识。
- UI：按钮/选择/标签；输入与表单；导航/分页/进度；卡片/弹窗/辅助信息；状态/异常/恢复；表格；卡牌确认与反馈；活动配置/技能状态/监督输入；窄屏与长内容。
- 应用：倡导横幅、教育支持海报及合作单页、研究报告封面及内页、企业官网区块、成长支持插画应用。产品事实来自公司材料，演示数据明确标注。
- 同一 Obsidian Canvas：新素材与状态样板在顶部，原始参考和未通过方案保留在下方。独立文件、交互 HTML、可复用 CSS/JS、来源清单、提示词与素材包同时交付。

## 完成检查

执行者检查图像主体、原始风格关系、文字准确性、透明边缘、比例、对齐、图形完整性，以及样张组合效果。模型成功出图不等于素材通过。

浏览器检查图像加载与样张边界、核心窄屏布局、选择不提交、确认后独立反馈、返回查看不重复提交、弹窗关闭焦点返回。检查只针对设计样板，不推断生产系统已满足这些保证。

用户保留品牌表达和视觉验收权。当前工作授权设计与本地制品，不修改业务边界、生产前端或已认可技能标准。

## 制作状态与可复用边界

现有标识和角色为原图；矢量图标与容器可编辑；生图为位图。所有新材料均为候选。HTML/CSS/JS 是可复用样板，未接后端，不声称生产组件已替换。印刷色彩、出血和正式字体授权按实际交付场景另行校准。
