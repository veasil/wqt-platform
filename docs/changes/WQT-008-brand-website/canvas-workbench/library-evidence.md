- 全部采用内置 image_gen，没有使用付费 API CLI 或改用其他生成模型。成功提示词与参照方式见 generation-prompts.json；去背景失败不计入交付数。

## 工程回顾

改变的假设：公司三折页可直接作为业务表达依据；本次缺口主要是视觉制作与交付密度，不是继续索取背景信息。

新增约束：原有标识 / 角色保持源文件，新增图形均注明候选；语义分类独立；透明素材须检查 alpha；设计样板交互保证只适用于样板。

遗留：现有标识仍是位图，正式矢量母版、印刷参数和字体授权需按实际交付校准；部分背景由文字描述而非图片输入生成，需要用户检验品牌精度。HTML/CSS/JS 是可复用设计样板，尚未接入实际业务。白板和工作区资产使用单向同步，人工编辑重建前保留备份。

架构与 schema：无业务架构、数据、认证或权限变化；未修改生产页面或已认可产品技能。

值得理解：素材成功生成、组合工艺检查、用户视觉验收是三个不同状态；有 alpha 通道不必然是真透明，需确认存在全透明像素；图形语义与业务分类分开，不能靠颜色推导领域映射。
