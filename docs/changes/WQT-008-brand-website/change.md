## 目标与范围

2026-10-14 范围更新：用户要求先读企业材料后做 VI，并进一步明确直接持续工作、不再要求补充材料。四份材料阅读后，本轮已制作十页 VI 视觉提案与资产包，见 [VI V2 交付检查](vi-v2/evidence.md)。新图形和组合是提案，原有资产保留；官网实现继续暂停。

目标：形成可实际预览和操作的品牌官网首页、视觉资产与组件状态样板，以及信息层级和动效规范，供用户判断首版设计方向。

范围：品牌表达、首页内容结构、学校/企业/资方三条合作阅读路径、产品介绍、响应式导航、合作弹窗、组件状态、可访问性与浏览器检查。用户授权的是首版设计探索；候选文案与设计标准不是最终商业发布标准。

非目标：生产网站替换、部署、咨询后台、用户数据采集、交易、融资披露、品牌 VI 定稿。不涉及领域模型、认证、数据库、生产 API。

事实来源：仓库 README；docs/watcher-update/2026-夏.md；public/brand 产品标识、小伍和公众号二维码；WQT-005 原型中的透明公司标识。没有提供客户名单、合作案例、资质、团队履历、业务指标、融资信息，因此不编造此类内容。
