# 首页视觉原型 · 交付记录

2026-10-18，依据用户“先做一个页面，主要看视觉设计”，完成一个数智免疫力计划首页。没有将本轮扩展为五页正式站点或生产部署。

## 视觉与内容

品牌蓝、暖白和少量金色；首屏大标题与完整儿童/家庭场景并置，四类行动集中分流；桌游使用浅蓝编辑区，开发者使用品牌蓝区，守望者使用暖色陪伴图文，CFAI以灰绿形成独立栏目识别。后续含行动观察、调研邀请、公司介绍、多方参与与联系区。

复用9个已有图片文件，静态页面出现13处图片。新文案是用户授权的设计示例；概念插画不作为真实活动照片。原型未虚构合作Logo、认证人物、付费金额或效果数据。认证、测评、媒体、联系方式与正式入口在相应交互预览中说明尚待接入。

## 产物与实际验证

- output/wqt-company-home/index.html及assets、CSS、JS组成可编辑文件夹版本。
- output/wqt-company-home/preview.html为约22.6MB单文件内嵌版本，静态图片、切换内容和弹层图片均可离线读取。
- homepage-desktop.png、homepage-mobile.png、homepage-full.png为真实浏览器截图。已目视检查首屏、移动首屏与整页节奏。
- 1440、1024、768、390、320px均无页面横向溢出。
- 12种弹层均可打开、Escape关闭并将焦点返回触发按钮；桌游/研究/活动切换及键盘左右键通过；移动导航展开、跳转、关闭通过。
- 调研仅本地交互预览，选择不保存、不提交。正式问卷、付款、登录、认证和外部系统未实现。
- 全部内部锚点有效，无JavaScript页面错误。文件夹版本图片与内容切换也通过。

检查记录见checks.json。验收仍以用户对视觉原型的判断为准。工程范围为静态独立页面，没有新增后端、数据、认证与发布边界；没有覆盖早先品牌故事HTML、白板和产品页面。后续若进入正式站点，需要独立确认正式内容、系统地址和实际表单行为。
