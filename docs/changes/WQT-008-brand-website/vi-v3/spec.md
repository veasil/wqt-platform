## 已发现的失败原因

亲自查看了原折页两面、单页、V2 总览、内嵌图像总览。V2 的斜矩形/橙色圆点在原材料中缺少相应母题，被扩大为主视觉；计划徽章被文字替代；原材料的科技空间、角色、金色倡导失去视觉权重。V2 大部分是论述展板，实际应用和复用资产不足。本版以原资产作为画面的主体，再通过留白、署名和有限的边框语法控制密度。
