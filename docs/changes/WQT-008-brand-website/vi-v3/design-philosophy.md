# 共在之光

边界给成长留下空间。护盾的折角来自已有徽章，细线向外铺开为版面容器；轮廓保持完整，信息区保持安静。每个切角和留白都经过精细校准，不将边框变成新的品牌标志。

深靛蓝承载科技空间，清白的纸面承载判断与证据。原有光流只在图像区域流动，金色落在倡导语和少量线索上。色彩的力量来自面积与位置的反复推敲，而不是全页发光。

人物与技术并置的温度来自现有资产。小伍、计划徽章和产品图像保有自己的细节与个性；企业署名给出稳定的来处。画面不抹去角色，也不把角色扩张为所有企业材料的主角。

文字采用稳固的中文骨架与收敛的英文索引。标题的停顿、标识的边界、段落的行长与细小标记以同一网格精密组织。成熟感应由逐项打磨的比例和秩序呈现，不能靠自称专业的文案代替。

同一种视觉语言在两种密度中成立：活动面允许徽章、光流与角色相遇，研究面留下大块空白与稳定的蓝色署名。精修不断减少互相争夺注意的元素，让每张应用只保留一个清楚的阅读入口。
