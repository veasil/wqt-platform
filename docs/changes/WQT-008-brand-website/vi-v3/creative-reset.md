## 主视觉生成提示词

以附件中的伍仟天品牌视觉为依据，重新创作一张具有成熟创意总监水准的品牌主视觉概念海报。不要做VI规范板，不要做幻灯片或网页。横向3:2，超精细艺术指导，富有想象力但克制，有可以形成长期品牌记忆的核心意象。

素材角色：第一张是现有倡导画面，供白蓝机器人造型、深靛蓝/钴蓝/温暖金色及儿童友好科技主题参考。第二张是品牌IP小伍，严格保持黑紫色刺发、青色透明护目镜、蓝紫耳机、紫色外套、黑短裤和运动鞋的识别特征；可重新绘制动作与光影。不要沿用第一张的照片人物，不要复制旧海报布局。原有logo与徽章不重新设计，此图不放logo。

创意“让成长，走在技术前面”：整幅画面的核心是一条由五条精密半透明钴蓝光带交织形成的、向远处开放的巨大立体成长路径，兼有玩具轨道、纸艺雕塑、科技装置的质感。光带在前景围成温柔的保护弧，在远景展开成开放地平线，而非封闭囚笼。路径上少量有尺度感的积木、创造工具和种子萌芽，表达探索与创造，不做密集图标。小伍与参考机器人位于画面中右侧，主动协作搭起一段金色桥面：小伍伸手将一块透光金色模块放到轨道缺口，机器人扶着模块另一端。角色占画面约1/5，表情专注友好，成为行动者；保持小伍动漫2.5D风格，机器人精致白瓷与蓝光材质，统一灯光。金光从连接点向远处铺展，构成唯一视觉焦点。非战斗、非游戏UI、非传统教育卡通。

布局：主体形成强烈斜向纵深、巧妙前后遮挡；左上约30%为安静的深靛蓝负空间，中文标题以精致大字号排版置于此处，清晰准确写两行“让成长，”“走在技术前面。”，下方小字“伍仟天科技 · 儿童友好 AI”。只出现这些文字。背景是深靛蓝摄影棚与无限空间过渡，有极淡蓝色空间层次。光带不是普通霓虹线，而是具有厚度、磨砂透明边缘与柔和体积光的真实设计物体。金色局部像暖阳而非金属奢侈品。整体像国际科技向善品牌的一次有记忆点的艺术海报：富有儿童主体性、开放、温度、可信赖。避免模板卡片、数据仪表盘、HUD边框、装饰性盾牌、大量星星、杂乱赛博朋克、紫粉渐变和廉价塑料感。
