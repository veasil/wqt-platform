# 伍仟天品牌官网 · 第一版视觉设计案

版本：2026-10-13，候选方向「科技向善，成长有据」。面向学校机构、企业与资方；待用户视觉与商业文案验收。

## 信息层级

| 次序 | 访客问题 | 内容与行动 |
|---|---|---|
| 1 品牌首屏 | 你是谁，在解决什么问题？ | 伍仟天公司标识；候选主张“为下一代，构建数智免疫力”；了解合作 / 探索产品 |
| 2 品牌方法 | 如何理解数智免疫力？ | 数字世界情境→体验中的选择→复盘与成长；五力交互介绍 |
| 3 产品证据 | 已经有什么具体产品？ | 《AI在5000天·伍力全开》、卡牌情境、计分与复盘；使用原有产品标识和小伍 |
| 4 合作入口 | 与我的机构有什么关系？ | 学校机构 / 企业合作 / 资方交流，各有不同议题；描述合作讨论方向，不承诺已交付能力 |
| 5 联系 | 下一步如何开始？ | 现有公众号二维码；网站内不模拟真实咨询提交 |

导航为锚点，首页为完整叙事。第一版不创建空的“案例/新闻/投资者关系”页面；有真实材料后再扩展。

## 视觉系统

以有编辑感的中文大标题、清晰的栅格、品牌蓝与暖白建立专业感。蓝色承接现有公司标识；淡黄用于视觉中的成长与连接，不作为错误/成功语义色。五力的 R/A/S/P/E 颜色保留在产品方法区。

| Token | 值 | 职责 |
|---|---|---|
| brand | #0755EB | 主行动、标题重点、装饰构图 |
| ink | #16243B | 正文与标题 |
| muted | #56637A | 次要正文 |
| paper | #F8F8F4 | 全站背景 |
| line | #D9DFE7 | 分隔、输入边界 |
| accent | #F1F28C | 合作区底、品牌图形辅助色 |
| dark | #10294B | 深色产品区 |
| error | #B42318 | 校验失败、错误反馈 |
| success | #166534 | 完成反馈 |

中文标题/正文：本机微软雅黑、苹方及 Noto Sans CJK SC 顺序回退，采用较大的字重与清楚的层级；中文是主要阅读语言，不让英文衬线字体决定版式。数字装饰使用 Arial Black / Segoe UI 的粗体。英文字段和章节编号使用 Consolas。首版无外部字体网络依赖。

桌面最大内容宽 1280px，左右间距 48px，12 列思路；正文上限约 38 个汉字/行。1024px 以下减少左右间距；768px 以下单列、导航折叠；375px 保持 20px 边距。触控目标至少 44px。

## 组件与状态

组件页可独立预览。覆盖主/次按钮、导航、标签、五力选择、合作面板、表单样板、状态提示、空状态和弹窗。

| 组件 | 默认 / 悬停 / 按下 | 键盘 / 选中 | 忙碌 / 失败 / 空 |
|---|---|---|---|
| 主按钮 | 蓝底白字；悬停加深；按下轻缩 | 外圈焦点不被裁切 | 禁用不响应；加载保持文字宽度 |
| 导航 | 清楚文本入口；悬停品牌蓝 | 锚点可直达；菜单展开状态有语义 | 无数据请求 |
| 选择按钮 | 有边界的大触控面积 | aria-pressed；键盘 Tab / Enter 可选 | 点击立即更新，URL 参数保存阅读选择 |
| 合作弹窗 | 从页面中心进入，同路径退出 | 原生 dialog，焦点限定；Escape 关闭，关闭后回触发者 | 实际二维码加载失败提供说明 |
| 表单样板 | 可见 label 与用途说明 | 焦点圈；错误关联字段 | 仅组件页演示校验/处理中/演示成功，明确不会发送 |
| 状态与空内容 | 文案+颜色共同表达 | aria-live 宣读动态反馈 | 错误提供下一步；空状态提供返回入口 |

首页不放没有接通的咨询提交表单。表单状态只出现在组件评审页；没有外部请求，也不持久化输入。

## 动效

| 场景 | 时间 | 行为与用途 |
|---|---|---|
| 首屏出现 | 500ms | 标题/图形轻微上移并淡入，最多三步；迅速建立层级 |
| hover/pressed | 160–200ms | 色彩反馈与 1–2px 位移；让操作目标清晰 |
| 五力与合作切换 | 180ms | 新内容短暂淡入；不让主容器跳高 |
| 弹窗 | 220ms | 轻缩放+淡入；保留原生焦点行为 |
| 移动菜单 | 180ms | 直接展开，及时响应关闭 |

不使用持续自动旋转、滚动劫持、鼠标跟随倾斜或强制入场等待。prefers-reduced-motion 下停用位移、入场和顺滑滚动，信息一直完整可读。动效仅影响 transform/opacity；颜色过渡独立列出。

## 内容与边界

第一版标题、品牌方法、合作议题是可评审文案，未经商业定稿。产品名、五力名称与基本计分/复盘能力来自仓库。资方交流暂呈现产品、场景与合作方向；没有数据来源时不展示营收、覆盖学校数、市场规模、融资状态、客户标识或研究结论。

后续需用户提供/确认：公司品牌定位一句话、学校与企业的真实合作方式、案例与授权图片、团队/资质资料、资方材料公开边界、最终联系渠道、备案与法律页。它们影响可信度与正式发布，不阻塞本次视觉探索。
