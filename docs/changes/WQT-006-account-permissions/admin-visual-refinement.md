# WQT-006 · 平台界面视觉与弹窗修订

2026-10-12需求方在v2验收通过后补充：新增组织或账号不能向下延长、未绑定对象不展开、现有审美需改善。本轮只修订前端展示，v2已确认的账号、身份验证与权益规则保持。

## 范围与交互

新增绑定使用独立居中弹窗，打开时隐藏账号列表框，返回恢复列表；已有账号列表在固定最大高度内滚动，新增入口及底部操作保持独立。密码/短信验证和请求恢复沿用已验收流程。

用户列表移除所有行展开；只有有绑定账号的用户显示“查看N个账号”，打开独立详情弹窗。没有绑定账号显示文字状态，没有箭头或查看入口。新增和详情不撑长原列表。

统一低饱和绿与深蓝、卡片圆角、数字层级、行间距和操作间距；账号弹窗采用头像字标、名称、组织/角色、当前权益的层级，并保留账号编号。键盘焦点与减少动画偏好可用。

## 验证与状态

admin构建通过。真实HTTP/PG/Redis浏览器回归通过：登录、独立邀请验证弹窗及新增绑定、容量保持、账号切换、操作恢复。合成浏览器回归通过，新增验证选择框打开表单后隐藏且返回高度保持、未绑定用户没有查看入口、绑定详情独立弹窗。实际8186环境桌面/390px手机截图检查通过，页面无脚本异常。

截图位于仓库外的 `admin-refinement-v3`。本轮仅更新admin静态构建，不重启或重建验收数据库，不改动用户的有效登录会话。没有新增架构、数据库迁移或依赖。后续管理详情继续采用独立弹窗/详情页，避免行内纵向展开。本机更新已交付，新增视觉反馈由用户复核；v2业务验收结论仍保留，不推导生产发布。


## 2026-10-13命名修订

需求方明确组织权益名称：个人合伙人、团队合伙人、城市合伙人。账号展示对应的“个人合伙人旗下权益 / 团队合伙人旗下权益 / 城市合伙人旗下权益”，到期或停用仍明确标识；组织名称不混入剩余次数。登录标题、浏览器标题、平台导航与移动标题、运营页品牌标识使用“伍仟天”。

仅修改平台端展示文案，底层personal/group/city枚举、容量、期限和授权保持。组织名称里的次数来自验收播种数据，本机独占合成库将原3个带状态说明的验收组织改名为验收团队甲/乙/丙，并同步新播种；不批量清洗真实组织名。次数继续在独立统计字段展示。已构建更新到8186，前端恢复测试6项通过，运营合成浏览器回归通过。
