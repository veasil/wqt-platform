## 目标与范围

将组织拥有的稳定业务账号与手机号登录身份分离，支持一个人绑定多个组织账号。保持组织=租户、账号唯一所属组织、换绑不移动账号与历史场次、角色属于账号、套餐终身共两次换绑等已确认规则。实现与测试以[执行方案](../../account-permissions-implementation-plan-2026-10-11.md)为输入；第8节未决事项不由执行者默认批准。

## 非目标

微信接入、客户集团层级、支付渠道自动扣款、未确认的自动运营；生产迁移和部署不从本次代码验证授权推导。保留无关工作区文件。
