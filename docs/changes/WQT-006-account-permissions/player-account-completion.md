# 新版账号切换、会话恢复与体验完成

来源：2026-10-14需求方要求新版不再依赖my.html，指出退出/返回后登录丢失、切换账号及权益未完成，并明确“平台管理端可开通体验权益，用户激活后连续30天，凭借活动码开局”。本条覆盖此前平台开通时立即开始30天的语义，不沿用旧“首次激活一个自然月”。

## 修复范围

- 新版删除所有my.html跳转；权益、下载、创建活动列表/成绩、旧场次读取和卡牌资料都在新版页面/弹窗展示。活动申请写权限仍按既有账号模型503门槛，明确说明未开放，不导回旧页面或擅自开启权限。注册/找回密码为独立现有认证页，不等同my.html。
- 当前登录恢复：新增GET /api/auth/session经authenticateIdentity读取当前Redis会话与PG身份/实时绑定；刷新/返回不重新密码登录或重签期限。恢复失败仅401/身份不可用清除凭证，依赖503/网络失败保留token并给重试。
- 原因：player入口以前无条件entry()，显示未登录；my.html退出动作会移除共享token并返回旧根首页。没有把缺少内存user误判为真实登录失效；不将已有localStorage缓存当认证依据。
- 账号切换为完整中央组件，含当前账号、组织、角色、权益期限、选中标记和取消。真实select-account后清理界面临时结果及旧账号请求上下文、读取新账号数据；不转移或结束原场次。进行中场次的倒计时继续，界面明确提示；录音未保存、正在写入或结果未确认时阻止切换并说明。
- 新版权益页GET /api/me/entitlements区分账号付费权益与本人体验，列出实际开局/下载/AI能力，不冒称学习平台授权已打通。
- 现有仅当前登录会话：显示本次登录/过期时间；没有历史登录日志、IP或设备表，不能伪造历史登录记录。

## 体验规则与迁移

identities增加trial_granted_at及trial_grant_consumed_at两列，保留既有trial_started_at/trial_until/trial_activated_at。平台开通只写待激活授权，不开始期限；用户在有效绑定免费守望者账号中激活，写开始时刻及+30×24小时，消费该次授权。原trial_activated_at保留首次激活时间，平台再次授权不抹除已有首次信息。

平台重复开通待激活授权拒绝；体验中重复开通拒绝；到期后平台可再次开通。没有待激活授权不能激活；付费账号须切换到免费守望者账号激活。激活使用固定请求号、同连接事务、账号→身份锁顺序和操作审计；同授权并发不同请求号只有一个生效，相同请求号返回原结果，撤销绑定后不能借历史成功绕过鉴权。

现有正在生效的体验期限不修改；新增待激活列为空的老记录继续按trial_until有效性判断。这里是明确的行为修订而非纯视觉重构。平台端文案和待激活标记同步改变。生产尚未迁移或发布；回退保留新列与审计，旧代码会忽略待激活授权，不能把旧“平台直接开始体验”继续描述为新规则。

### 验收账号隔离补充

发现手动浏览器脚本曾复用公开给用户的本机验收身份；服务采用单身份单会话，新测试登录会撤销用户先前的会话。不能把自动化自身造成的退出都归为用户操作或旧页面问题。

UAT种子已分离：用户验收16600000888、自动验证16600000889，各有独立身份、组织、账号和Redis会话。全部manual/player脚本改用自动验证身份，后续不再登录用户验收身份。重新运行账号恢复/切换/待激活与激活完整浏览器链路通过，截图已实际查看。本机服务更新时合成验收库会重建，不代表真实业务数据保留或生产发布。
