## 迭代工程复盘

- 改变的假设：当前用户组织不能证明历史场次归属；临时 SQLite 路径也不能证明 PostgreSQL 测试隔离。
- 新增约束：数据库冻结场次归属；创建与转组织在同一用户行锁上串行化；文件上传完成后再次校验权限，失败清理私有对象。
- 保留债务：旧认证/管理路由继续渐进模块化；历史归属人工核实、旧公开 OSS 处理及实际外部服务联调留给发布阶段。
- 值得理解：归属与实时访问权是两个规则；事务必须固定同一连接才能保护并发；子代理返回通过必须以实际执行场景和集成证据复核。
