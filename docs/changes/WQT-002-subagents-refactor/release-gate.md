# WQT-002 · 正式发布 gate

状态：待发布负责人准备证据、需求方确认。当前授权只覆盖隔离实现与验证，本轮未执行生产操作。

| 发布前证据 | 负责人角色 | 通过条件 |
|---|---|---|
| 存量归属盘点 | 数据负责人 | 显式指定迁移数据库运行只读 audit，复核 unknown 数量及报表影响；不得用当前成员关系回填历史 |
| 备份与恢复演练 | 发布负责人 | 保存可恢复备份；在副本验证迁移、数据约束及回退步骤 |
| 历史公开文件 | 存储负责人 | 盘点旧 OSS 地址、对象 ACL 和 bucket 策略，确定撤销公开访问或重新生成对象的方案；新接口不能自动收回旧公开地址或已经下载的副本 |
| 管理登录 | 账号负责人 | 管理员密码及真实验证码通道可用，验证完整登录；开发捷径默认关闭 |
| 外部服务 | 发布负责人 | 实际 OSS 私有访问、短信和 AI 调用联调完成；当前自动测试使用替身 |
| 最终验收与发布版本 | 需求方 / 发布负责人 | 业务验收记录关联准确 SHA，批准迁移与发布窗口 |

回退必须保留固定组织归属和鉴权边界。不能直接部署旧版按当前用户组织查询的代码，不能删除归属列后宣称回退完成。迁移异常先停止相关写入，由负责人根据副本演练证据选择向前修复或恢复备份，记录期间新增数据的处理。

多组织成员、代理授权、产品独立权益与历史数据保留期限仍为独立决策，不由本次迁移推断。
