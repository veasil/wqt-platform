# 预发布执行与证据记录

本手册适用于明确指定的预发布环境。合成 CI 演练仅证明所覆盖 schema 的迁移/恢复逻辑；不能证明整库备份完整、容量、真实对象存储或上线恢复时间。

## 执行前输入

| 输入 | 当前状态 | 禁止替代方式 |
|---|---|---|
| 预发布地址、部署版本与环境负责人 | 待指定 | 不从旧文档中的生产地址推断 |
| 脱敏副本来源、脱敏方式、备份时间及主库/卡牌库拓扑 | 待指定 | 不直接复制生产用户资料或密钥到 CI |
| 独立 OSS bucket/prefix 与测试对象 | 待指定 | 不修改线上旧对象 ACL |
| 测试管理员/组织 A/B/个人账号与短信接收人 | 待指定 | 不向真实用户群发验证短信 |
| 短信与 AI 调用限额、可用测试配置位置 | 待指定 | 不将凭据写入制品或 PR |

## 执行顺序

1. 核对环境标识与版本，停用副本中的生产短信/OSS/AI 配置及自动任务。预发布数据副本可能携带生产 system_settings；不能只改环境变量就假设它们不会覆盖配置。
2. 建立主库与卡牌库备份。记录 SHA、数据库版本、对象清单、备份校验摘要、耗时；若是两套库，分别恢复并核对引用关系。原备份保存在受控位置，不上传公开 GitHub。
3. 通过显式 WQT_MIGRATION_DATABASE_URL 运行只读归属盘点。记录 total、unknown、组织/个人计数及关联冲突，历史当前成员提示只能当线索。
4. 在副本执行目标版本迁移，重跑盘点和约束检查；核对旧场次 unknown 不进入组织报表，新组织场次固定归属。
5. 浏览器完成管理员完整登录、组织 A 创建场次、选牌事件、结算复盘、上传/下载；转到 B 后旧链接拒绝、A 管理员仍可访问、B 报表不出现旧场次。另测个人场次与跨组织活动拒绝。
6. 在明确测试资源上验证短信消费/重放拒绝、OSS 匿名访问拒绝与认证下载、AI 正常及撤权路径。记录脱敏请求结果，不记录验证码、token 或内容资料。
7. 恢复到新的预发布数据库，核对场次、文件 metadata、组织关联和约束。验证对象本身也存在；数据库恢复不会恢复已经删除的 OSS 对象。
8. 发布负责人汇总失败/未执行项、备份恢复时间与写入冻结策略，需求方确认发布 gate。恢复点后的新增写入必须有保留或重放方案，不能默认为可丢弃。

## 结果模板

| 场景 | 版本 / 环境 | 数据或请求摘要 | 预期 | 实际 | 结论 / 责任人 |
|---|---|---|---|---|---|
| 迁移前后盘点 | 待填写 | 聚合计数 | 历史不猜测 | 未执行 | 待资源 |
| 备份恢复 | 待填写 | 备份摘要与对象清单 | 数据、序列与约束保持 | 未执行 | 待资源 |
| 完整浏览器业务链路 | 待填写 | 测试账号别名 | A/B 权限符合 gate | 未执行 | 待资源 |
| 真实外部服务 | 待填写 | 测试资源别名 | 短信/私有文件/AI 正常 | 未执行 | 待资源 |

未执行和失败都不能标为通过。最终发布沿用 [WQT-002 发布 gate](../WQT-002-subagents-refactor/release-gate.md)。
