## 工程复盘与剩余事项

被推翻的假设：分域前同源存储接续不等于跨子域登录；仅添加管理表单不足以改变数据库固定容量。新增保证：身份会话接续严格来源与实时角色校验；组织容量不随级别强绑；缩容不抹历史，事务和锁确保新绑定不超额；失败接续保留其他已有效的admin登录。新增可空组织授权标识只解决真实的内部授权差异，没有建立另一套租户或通用SSO平台。
